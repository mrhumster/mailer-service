# mailer-service

GoCast background worker that delivers email notifications. First (and currently
only) message type: **email verification** consumed from the asynq queue
`emails` and sent via SMTP — with a log-only fallback for development.

Built on the same worker skeleton as transcoder/thumbnail:

- `github.com/mrhumster/go-shared` (`worker`, `config`, `metrics`) via `replace => ../shared`
- asynq queue `emails` (Redis DB 2, KEDA ScaledObject `asynq:{emails}:pending/active`)
- Prometheus `/metrics` on 9090 (liveness probe)

## Message types

| Task | Payload |
| --- | --- |
| `email:verification` | `{user_id, email, token}` → email with `{FRONTEND_URL}/verify?token=...` |

Producer: identity-service enqueues the task right after creating a
verification token (register + resend).

## Modes

- `SMTP_ADDR` set → real delivery via `net/smtp` (`SMTP_USER`/`SMTP_PASS`/`SMTP_FROM`).
- `SMTP_ADDR` empty → **log mode**: the rendered message is printed with
  `log/slog`, delivery always succeeds (dev default).

## Config (env)

`REDIS_ADDR`, `REDIS_DB` (default 2), `redis-password` (secret), `WORKER_CONCURRENCY`,
`WORKER_SHUTDOWN_TIMEOUT`, `METRICS_ADDR` (default empty → metrics off),
`SMTP_ADDR`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `FRONTEND_URL` (default `https://example.com`).
